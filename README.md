# calculator-template
## ⚡ ClipForge: AI viral clip generator

This repo also contains **ClipForge** ([`clipforge/`](clipforge/README.md)), a web app that turns long videos into
viral 9:16 shorts with face tracking, animated captions, and AI-written posts and hashtags for every platform.

```bash
pip install -r clipforge/requirements.txt
uvicorn clipforge.app:app --port 8000   # open http://localhost:8000
```
